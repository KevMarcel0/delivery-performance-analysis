# Data

The CSVs aren't included because of their size.

1. Download the Olist dataset from Kaggle: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
2. Unzip it and put the CSVs in this folder.
3. Run `notebooks/02_clean_and_join.ipynb` to create `delivery_clean.csv`, the cleaned table used for the SQL, Excel, and Tableau work.

Files used:
- `olist_orders_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `olist_customers_dataset.csv`
- `product_category_name_translation.csv`
